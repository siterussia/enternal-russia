ENTERNAL RUSSIA — стартовый проект Android-лаунчера

Что умеет версия 1.0:
- Показывает название ENTERNAL RUSSIA.
- Проверяет наличие приложения с package id com.kranin.
- Кнопка ИГРАТЬ открывает установленный клиент через Android launch intent.
- Не изменяет и не копирует игровой кеш.

Важно:
1. Папка Android/data/com.kranin/files сама по себе не подтверждает, что package id установленного APK — com.kranin.
2. Если клиент не обнаруживается, проверь точный package/applicationId установленного APK. Его можно посмотреть в сведениях о приложении или через APK analyzer.
3. Размер 3,54 ГБ пока указан как предоставленная пользователем информация; лаунчер ещё не проверяет содержимое этой папки из-за ограничений Android.
4. Это исходный проект, не готовый APK. APK собирается через GitHub Actions после загрузки проекта в репозиторий.
5. Используй только файлы и ресурсы, на распространение и изменение которых у тебя есть разрешение.

Сборка:
- Создай GitHub repository.
- Загрузи содержимое ZIP в корень репозитория.
- Открой вкладку Actions и запусти Build Android APK.
- Скачай artifact eternal-russia-debug-apk.
